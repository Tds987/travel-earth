# Travel Earth

A calm, Google Earth–style travel guide: see where you're going, why each place matters, and what it costs.

## Develop

```sh
npm install
npm run dev          # local dev server at http://localhost:5173
npm run build        # type-check + production build into dist/
npm run lint         # oxlint
npm run format       # prettier --write
```

Deployed on Vercel (Vite preset, build `npm run build`, output `dist`).
See `CLAUDE.md` for the product brief and `DECISIONS.md` for the decision log.
